Day 07 - Automating Cloud Infrastructure with Terraform & Ansible
🔹 Ansible - Setup Nginx with Custom Config
- name: Setup Nginx eith Custom Config
  hosts: all
  become: yes
  tasks: yes
    - name: Install nginx
      yum:
      name: nginx
      state: present
    - name: Copy custom nginx.conf
      copy:
        src: nginx.conf
        dest: /etc/nginx service
    - name: Start nginx service
      service:
        name: nginx
        state: started
        enabled: yes
